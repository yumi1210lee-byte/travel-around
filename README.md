# ✈️ 旅行手帳 Travel Around

個人用的旅行小 App，把一趟旅程需要的資訊收在同一個地方：

- **航班**：航班編號、起降時間、航廈、登機門、座位、行李額度、訂位代號（一鍵複製），並可直接查詢即時航班動態（Google／Flightradar24）
- **住宿**：地址（一鍵開 Google 地圖）、入住／退房時間、自動計算晚數、訂房編號、電話、訂房連結
- **行程**：依日期與時間排序的景點、美食、交通、購物安排
- **清單**：行前準備／行李清單，內建常用項目範本
- **總覽**：出發倒數、旅行中「今天的安排」、下一班航班、今晚住哪裡、花費加總（依幣別）、每日時間軸

其他特色：

- 📱 手機優先設計，可「加入主畫面」當成 App 使用
- 📴 **可離線使用**：開過一次之後，出國沒網路也打得開
- 🔒 **資料只存在自己的裝置**（瀏覽器 localStorage），不會上傳到任何伺服器
- 💾 可匯出／匯入 JSON 備份檔，換手機也能搬家
- 🌙 支援深色模式

## 開始使用

### 1. 用 GitHub Pages 免費架站（建議）

1. 到 GitHub 專案頁面 → **Settings** → **Pages**
2. **Source** 選 **Deploy from a branch**
3. **Branch** 選放有這些檔案的分支（例如 `main`），資料夾選 **/ (root)**，按 **Save**
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/travel-around/`

> 網站程式碼是公開的，但你輸入的旅行資料只存在你自己的手機／電腦裡，別人打開同一個網址看不到你的資料。

### 2. 加到手機主畫面

- **iPhone（Safari）**：打開網址 → 分享按鈕 → **加入主畫面**
- **Android（Chrome）**：打開網址 → 右上角選單 → **安裝應用程式**／**加到主畫面**

> iPhone 上建議一定要「加入主畫面」再使用：Safari 對一般網頁的資料可能在一段時間沒開之後清掉，加入主畫面的 App 比較不會。

### 3. 在電腦上本機執行

不需要安裝任何套件，只要有 Python 3：

```bash
python3 -m http.server 8000
```

然後打開 <http://localhost:8000>。

## 備份很重要

資料存在瀏覽器裡，以下情況可能會遺失：清除瀏覽器資料、換手機、刪掉主畫面的 App。

👉 到 **設定與備份**（首頁右上角）按 **匯出備份**，把 `.json` 檔存到雲端硬碟或傳給自己。在新裝置上按 **匯入備份** 即可還原。

## 專案結構

```
index.html            App 入口
manifest.webmanifest  PWA 設定（名稱、圖示）
sw.js                 Service worker（離線快取）
css/style.css         樣式（含深色模式）
js/app.js             路由、事件處理
js/views.js           各畫面的 HTML
js/forms.js           新增／編輯表單
js/store.js           資料存取（localStorage、匯入匯出）
js/utils.js           日期、格式化、時間軸等純函式
js/constants.js       類別、幣別、行李清單範本
js/sample.js          範例旅程
icons/                App 圖示
tests/                單元測試
```

純 HTML／CSS／JavaScript（ES modules），沒有任何外部套件或建置步驟。

## 開發

```bash
npm test
```

用 Node.js 內建的測試工具執行 `tests/` 裡的單元測試（需要 Node 18 以上）。

App 會「先顯示快取、同時在背景下載新版」，所以部署新版之後，通常要把 App 關掉再打開一次才會看到更新。若有新增或改名檔案，記得更新 `sw.js` 裡的 `ASSETS` 清單，並把 `CACHE` 版本號加一（例如 `travel-around-v2`）。

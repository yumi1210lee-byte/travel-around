# ✈️ 旅行手帳 Travel Around

個人用的旅行小 App，把一趟旅程需要的資訊收在同一個地方：

- **航班**：航班編號、起降時間、航廈、登機門、座位、行李額度、訂位代號（一鍵複製），並可直接查詢即時航班動態（Google／Flightradar24）
- **住宿**：地址（一鍵開 Google 地圖）、入住／退房時間、自動計算晚數、訂房編號、電話、訂房連結
- **行程**：依日期與時間排序的景點、美食、交通、購物安排
- **清單**：行前準備／行李清單，內建常用項目範本
- **換匯**：即時匯率換算，上下兩欄都能輸入、一鍵對調幣別，附常用金額快速對照表；首頁右上角或旅程裡的「換匯」分頁都能開
- **分享旅程**：把一趟旅程用連結或文字版傳給旅伴（見下方「分享旅程」）
- **總覽**：出發倒數、旅行中「今天的安排」、下一班航班、今晚住哪裡、花費加總（依幣別，並自動換算成主要幣別）、每日時間軸

其他特色：

- 📱 手機優先設計，可「加入主畫面」當成 App 使用
- 📴 **可離線使用**：開過一次之後，出國沒網路也打得開
- 🔒 **資料只存在自己的裝置**（瀏覽器 localStorage），不會上傳到任何伺服器
- 💾 可匯出／匯入 JSON 備份檔，換手機也能搬家
- 🌅 黃昏天空配色：淺色模式是夏日傍晚的天藍→杏桃→橘，深色模式是冬夜的深藍→寶藍（會跟著手機設定自動切換）

## 開始使用

### 1. 用 GitHub Pages 免費架站（建議）

1. 到 GitHub 專案頁面 → **Settings** → **Pages**
2. **Source** 選 **Deploy from a branch**
3. **Branch** 選放有這些檔案的分支（例如 `main`），資料夾選 **/ (root)**，按 **Save**
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/travel-around/`

> 網站程式碼是公開的，但你輸入的旅行資料只存在你自己的手機／電腦裡，別人打開同一個網址看不到你的資料。

### 2. 加到手機主畫面

- **iPhone（Safari）**：打開網址 → 分享按鈕 → **加入主畫面**
- **Android（Chrome）**：打開網址 → 右上角選單 → **安裝應用程式**／**加到主畫面**

> iPhone 上建議一定要「加入主畫面」再使用：Safari 對一般網頁的資料可能在一段時間沒開之後清掉，加入主畫面的 App 比較不會。

### 3. 在電腦上本機執行

不需要安裝任何套件，只要有 Python 3：

```bash
python3 -m http.server 8000
```

然後打開 <http://localhost:8000>。

## 備份很重要

資料存在瀏覽器裡，以下情況可能會遺失：清除瀏覽器資料、換手機、刪掉主畫面的 App。

👉 到 **設定與備份**（首頁右上角）按 **匯出備份**，把 `.json` 檔存到雲端硬碟或傳給自己。在新裝置上按 **匯入備份** 即可還原。

## 分享旅程

在旅程頁右上角按分享按鈕，有三種方式：

| 方式 | 適合 | 之後修改會同步嗎 |
| --- | --- | --- |
| 🔄 **同步連結**（推薦） | 給旅伴，讓他隨時看到最新行程 | ✅ 會。你改了之後，對方打開 App 就會更新 |
| 📸 **一次性連結** | 傳一份副本就好 | ❌ 不會。要更新得重新分享 |
| 📝 **文字版行程** | 貼到 LINE 群組給沒裝 App 的人看 | ❌ 不會 |

分享前可以選擇隱藏訂位代號／訂房編號／訂房連結（預設隱藏）、隱藏金額、是否包含行李清單。

### 同步連結怎麼運作

- 旅程會依你選的分享選項，上傳一份到 Firebase 雲端資料庫，連結裡只放一組隨機、無法被猜到的分享代碼
- 你之後每次修改，App 會自動上傳最新版本（沒網路時會等連上再傳）
- 對方的旅程是**唯讀**的，打開 App 或旅程時會自動檢查更新；行李清單可以自己新增、勾選，不會被蓋掉
- 對方可以按「改成我可以編輯」，變成自己的旅程（之後就不再同步）
- 你按「停止分享」會刪除雲端上的資料，對方會保留最後一次同步的版本
- App 會在背景自動建立匿名帳號，你和對方都不需要註冊。注意：同步連結只能在「建立它的那台裝置」上更新；換手機後要停止分享再重新建立

### 隱私

- 一次性連結：旅程資料壓縮後放在連結 `#` 後面，不會傳到任何伺服器（包括 GitHub）
- 同步連結：資料存在你自己的 Firebase 專案裡。只有知道分享代碼的人能讀取那一份，沒辦法列出所有分享，也只有建立的人能修改或刪除
- 不管哪一種，拿到連結的人都看得到內容，請只傳給信任的人

### iPhone 小提醒

加到主畫面的 App 和 Safari／LINE 裡開的網頁，資料是分開存的。如果點連結後是在 Safari 或 LINE 裡打開，想加到主畫面的 App，就複製連結，打開 App →「設定與備份」→「匯入分享的旅程」貼上。

## Firebase 設定（同步連結用）

設定檔在 `js/firebase-config.js`（`apiKey`、`projectId` 本來就是公開的值，不是密碼）。Firebase 主控台需要：

1. **Firestore**：建立資料庫（Standard 版、正式版模式），位置建議 `asia-east1`
2. **Authentication**：登入方式啟用「匿名」
3. **Firestore → 規則**：把專案裡 [`firestore.rules`](firestore.rules) 的內容整段貼上，按「發布」

想停用同步功能，把 `js/firebase-config.js` 改成 `export const FIREBASE = null;` 即可，其他功能不受影響。

## 匯率說明

App 會依序嘗試以下免費、不需金鑰的匯率來源，第一個失敗就自動改用下一個：

| 順序 | 來源 | 更新頻率 |
| --- | --- | --- |
| 1 | [Coinbase](https://www.coinbase.com/) 公開匯率 API | 即時 |
| 2 | [ExchangeRate-API](https://www.exchangerate-api.com)（Rates By Exchange Rate API） | 每日 |
| 3 | [fawazahmed0/exchange-api](https://github.com/fawazahmed0/exchange-api)（jsDelivr） | 每日 |

- 畫面上會標示目前用的是「即時匯率」還是「每日匯率」、來源與更新時間
- 換匯頁開著時約每 5 分鐘自動更新，也可以按右側的重新整理按鈕
- 最後一次的匯率會存在手機裡，沒網路時照樣能換算（會顯示是哪個時間的匯率）
- 顯示的是市場中間價；實際在銀行、換匯所或刷卡會有匯差與手續費，僅供參考

## 專案結構

```
index.html            App 入口
manifest.webmanifest  PWA 設定（名稱、圖示）
sw.js                 Service worker（離線快取）
css/style.css         樣式（含深色模式）
js/app.js             路由、事件處理
js/views.js           各畫面的 HTML
js/forms.js           新增／編輯表單
js/fx.js              匯率來源、快取與換算
js/fxview.js          換匯畫面
js/share.js           分享旅程（連結編碼、文字版、收到分享的畫面）
js/sync.js            同步連結的上傳與檢查更新
js/cloud.js           Firebase 匿名登入與 Firestore 存取（REST API）
js/firebase-config.js Firebase 專案設定
firestore.rules       Firestore 安全規則（貼到 Firebase 主控台）
js/ui.js              提示訊息、複製到剪貼簿
js/store.js           資料存取（localStorage、匯入匯出）
js/utils.js           日期、格式化、時間軸等純函式
js/constants.js       類別、幣別、行李清單範本
js/sample.js          範例旅程
icons/                App 圖示
tests/                單元測試
```

純 HTML／CSS／JavaScript（ES modules），沒有任何外部套件或建置步驟。

## 開發

```bash
npm test
```

用 Node.js 內建的測試工具執行 `tests/` 裡的單元測試（需要 Node 18 以上）。

App 會「先顯示快取、同時在背景下載新版」，所以部署新版之後，通常要把 App 關掉再打開一次才會看到更新。若有新增或改名檔案，記得更新 `sw.js` 裡的 `ASSETS` 清單，並把 `CACHE` 版本號加一（例如 `travel-around-v2`）。
